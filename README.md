## InvoiceMate

Lightweight invoice generator, with focus on simplicity and ease of use.

## Features

- Create invoices  
- Dynamic invoice templates using RazorLight  
- PDF generation using Playwright  

## Service Provision invoices

- Add professionals
- Track hours
- Set hourly rates
- Auto-calculate totals

## Deliverable invoices

- Add deliverables
- Set prices
- Set quantities
- Tax/GST support


## Tech Stack

- **Backend:** .NET 9 
- **Template Engine:** RazorLight  
- **PDF Renderer:** Playwright   
- **Testing:** XUnit, FluentAssertions  

- **Frontend:** Next.js 14 / App Router
- **UI Library:** Shadcn UI
- **State & Forms:** React Hook Form, Zod
- **Styling:** Tailwind CSS
